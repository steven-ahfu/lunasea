# Chaptarr

In **Settings → Configuration → Chaptarr**, enable the module for the current LunaSea profile. Enter the Chaptarr server URL and its API key from **Settings → General** in Chaptarr. Include the URL prefix if you use a reverse proxy. Add any required custom headers and tap **Test Connection**.

Open **Chaptarr** from the drawer. In **Library**, switch between ebooks and audiobooks. Tap a title to read its details, change monitoring, or ask Chaptarr to search your indexers for a release. **Queue** shows downloads in progress. **History** shows previous activity.

To add a title, tap **+**, search for a book, and choose a format. Select a root folder to add the book using that folder’s quality and metadata profiles. Configure at least one compatible root folder in Chaptarr for each format you use. Adding and searching for releases are separate actions. For a title already in the library, tap the search result to manage the local edition.
